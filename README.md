# KODEN
React + Vite. Портфолио на русском, одна страница.

## Запуск и сборка
`npm install`, затем `npm run dev`. Сборка: `npm run build`, папка `dist` подходит для любого статического хостинга (base: './').

## Что где править
- Проекты: `src/data/projects.js`. Пишите только факты, которые видны на самом сайте.
- Команда и Telegram: `src/data/team.js`. Фото участника: положите файл в `public/images/team/` и добавьте поле `photo`.
- Стили: `src/styles/index.css`. Размеры шрифтов и отступы заданы переменными в `:root`.
- Скриншоты: `public/images/projects/<slug>.webp`, 1348x926. Нижняя полоса обрезается в вёрстке (там значок хостинга).
- Перед публикацией замените og:url и og:image в `index.html` на свой домен.

Сайт не собирает данные и не содержит форм. Тема светлая или тёмная по настройке системы.
